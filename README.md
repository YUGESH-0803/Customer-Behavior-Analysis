# Customer Behavior Analysis

An end-to-end data analytics project exploring customer shopping behavior, purchasing patterns, and revenue trends using **Python (Pandas), MySQL, and Power BI**.

## Project Overview

The project starts with the raw customer shopping dataset, performs data cleaning and feature engineering in a Jupyter Notebook, uses MySQL queries for exploratory analysis, and presents business insights through an interactive Power BI dashboard.

## Tools & Technologies

- **Python – Pandas:** Data cleaning, missing-value treatment, transformation, and feature engineering.
- **Jupyter Notebook:** Exploratory data analysis and data preparation.
- **MySQL:** Business-focused analysis using aggregation, filtering, subqueries, CTEs, and window functions.
- **Power BI:** Interactive dashboard and visual reporting.

## Dataset

- **Records:** 3,900
- **Original columns:** 18
- **Customer identifier:** `Customer ID`
- **Purchase value:** `Purchase Amount (USD)`
- **Review ratings:** 3,863 populated values and 37 missing values in the original file.

The notebook fills missing review ratings using the median rating within each product category, creates age groups, maps purchase frequency labels to approximate day intervals, and removes the redundant `promo_code_used` field after checking it against `discount_applied`.

## Analysis Highlights

The SQL analysis addresses these business questions:

1. Revenue generated by male and female customers.
2. Customers who applied discounts but spent at least the overall average.
3. Five products with the highest average review ratings.
4. Average purchase amount for Standard versus Express shipping.
5. Customer count, average spend, and revenue by subscription status.
6. Five products with the highest discount-use rate.
7. Customer segmentation into New, Returning, and Loyal.
8. Top three purchased products within each category.
9. Subscription status among repeat buyers with more than five previous purchases.
10. Revenue contribution by age group.

## How to Run

1. Clone or download this repository.
2. Open `Customer_behavior_analysis.ipynb` in Jupyter Notebook or JupyterLab.
3. Update the CSV path in the notebook to the location of `customer_shopping_behavior.csv`.
4. Configure your local MySQL connection and create/use the `customer_behavior` database. Set credentials through environment variables (`MYSQL_USER`, `MYSQL_PASSWORD`, `MYSQL_HOST`, `MYSQL_PORT`, and `MYSQL_DATABASE`) rather than hardcoding passwords.
5. Run the notebook to prepare and load the `customer` table into MySQL.
6. Execute the queries in `Customer_behavior_analysis.sql`.
7. Open `customer_behavior.pbix` in Power BI Desktop.

## Objective

To turn raw customer shopping data into useful insights about customer preferences, purchasing behavior, discount usage, subscriptions, and revenue—supporting better, data-driven business decisions.
